Copy this onto paper

Write each item, then a comma. Any number of lines is fine.

  • Use a dark pen or marker on plain white paper.
  • Put a comma after every item. That is how I tell the letters apart.
  • Leave a little space after each comma, and skip a line between rows.
  • Write at your normal size, roughly the same size throughout.
  • Photograph from straight above, with no shadow of your hand or phone.

Your font

On a phone, use “Send it to myself” to put the file in Drive, email or Files. Fonts can be installed on a computer, not on a phone.

1. Install it on your computer

  1. Open your Downloads folder.
  2. Right-click the font file and choose Install. (Or double-click it, then click Install.)
  3. Close and reopen the app you want to use it in.
  1. Open your Downloads folder.
  2. Double-click the font file, then click Install Font.
  3. Close and reopen the app you want to use it in.

2. Use it

Microsoft Word (desktop)Yes. Pick it from the font menu. To send a document to someone, save it as PDF so they see your handwriting.
PowerPoint, Pages, KeynoteYes, once installed.
Photoshop, Premiere, DaVinci, Final CutYes, once installed. CapCut and Figma desktop: worth a try.
CanvaOnly on Canva Pro, Teams or Education: Brand Hub → Fonts → Upload. Free Canva can’t add fonts, so use the image instead.
Google Docs and SlidesCan’t use custom fonts. Send the PDF or image instead.
Word on the webProbably not. Check, or use the PDF.
Instagram, TikTok text toolsBuilt-in fonts only. Post the image instead.

One honest limit: the font draws each letter the same way every time, so a double letter (like “ll”) looks identical. The PDF and image add a tiny natural wobble. A font file can’t.
